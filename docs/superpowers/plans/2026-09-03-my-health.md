# My Health Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the My Health tab fully interactive for the study demo — manual appointments, medications, providers/portals, offline wallet card, optional PIN, and real Erase — with data staying on-device.

**Architecture:** Mirror Nearby: feature-local models + `HealthStore` interface (`InMemory` for tests, `PrefsHealthStore` for app) + `HealthController` (`ChangeNotifier`) provided via `HealthScope` from `AppShell`. Forms are pushed routes. Call / text / portal use injectable `LinkLauncher` and pure URI helpers. First launch seeds today’s demo sample once; Erase clears personal data and does not re-seed. Optional reminders are stored only (no OS notifications this award — `[PENDING FG]`).

**Tech Stack:** Flutter, `shared_preferences` (same as Nearby; web-demo friendly), `url_launcher`, `dart:convert` SHA-256 for PIN hash. No new paid deps.

**Out of scope:** NOW-3 Help Now emergency-card toggle, biometric unlock, MYH-5 export, MYH-6 portal FHIR, OS local-notification scheduling.

## Definition of done (PM terms)

Someone opens My Health, can add/edit/delete appointments, meds, and providers; call, text, or open a portal link; show a wallet card built from their entries offline; optionally lock the tab with a PIN; and wipe everything from More → Erase — without needing an account or network.
